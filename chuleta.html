02 · KIRO

Kiro en 10 líneas

Entrar

Sign in con AWS Builder ID (vale el correo del trabajo). Al abrir carpeta: Trust.

Atajos

Chat Ctrl+Shift+L · Terminal Ctrl+ñ · Paleta Ctrl+Shift+P.

Créditos

Plan gratuito: 50 al mes, se renuevan el día 1. Un "explica este archivo" ≈ 0,2. El evento da un código extra.

Diffs

Kiro propone, tú aceptas. "1 of N pending": revisa cada archivo, Accept o Reject.

Cómo pedirle las cosas

Un prompt bueno dice qué, dónde, cómo se llama y qué no tocar. Compara:

"Mejora el orquestador para que corte vídeos."

"Añade a orquestador.py una tool cortar_clip(s3_uri, inicio, fin) que de momento devuelva una ruta falsa de S3, con docstring en español que diga que la versión real usará ffmpeg. Inclúyela en la lista de tools del Agent, menciónala en el system_prompt y añade su llamada a probar_tools.py. No cambies nada más."

Qué revisar en un diff (10 segundos)

  1. Verde = lo que pediste. Nueva función con los parámetros y nombre que dijiste.
  2. Nada rojo que no pidieras. No borra tools, no cambia modelo ni región, no reescribe el prompt entero.
  3. Piezas conectadas. La tool existe, está en tools=[...] y el system_prompt la menciona. Si falta una, el agente nunca la usará.

Rechaza si toca un archivo que no nombraste. Después de aceptar: python probar_tools.py.

Si Kiro se queda en "Working..."

Espera un minuto. Si no, Cancel y vuelve a enviar el mismo prompt. No gasta créditos hasta que responde.

03 · AGENTE STRANDS

El esqueleto que ya tenemos

Un orquestador con tools falsas. El día 4 se sustituyen por las reales de una en una. Si una real falla, vuelve a la falsa: la demo no se para.

from strands import Agent, tool
from strands.models.bedrock import BedrockModel

@tool
def transcribir_video(s3_uri: str) -> str:
    """Transcribe el audio de un vídeo en S3 con timestamps.
    Real: Amazon Transcribe."""
    return "[00:00-00:05] Bienvenidos al partido de hoy."

model = BedrockModel(model_id="us.amazon.nova-pro-v1:0",
                     region_name="us-east-1")
orquestador = Agent(
    model=model,
    system_prompt="Eres el agente de localización. "
                  "Orden: transcribir_video, traducir_texto, generar_locucion.",
    tools=[transcribir_video, traducir_texto, generar_locucion],
)
orquestador("Localiza s3://demo-bucket/partido.mp4 al inglés")

Reglas que evitan horas perdidas

  • El docstring es lo que lee el modelo para elegir la tool. Escríbelo claro: qué hace, qué recibe, qué devuelve.
  • Prueba cada tool como función normal antes de dejar que el agente la elija: transcribir_video("s3://...").
  • Activa el log para la demo: logging.getLogger("strands").setLevel(logging.INFO). Se ve qué tool elige y por qué.
  • Nova Pro y Pegasus en us-east-1. Ray2 y Stability en us-west-2. Dos clientes boto3.

Sustituir una tool falsa por la real

import boto3
@tool
def traducir_texto(texto: str, idioma_destino: str) -> str:
    """Traduce texto al idioma destino (código ISO: en, fr, de)."""
    tl = boto3.client("translate", region_name="us-east-1")
    return tl.translate_text(Text=texto, SourceLanguageCode="auto",
                             TargetLanguageCode=idioma_destino)["TranslatedText"]

ComfyUI (estación con GPU)

  1. Templates → Wan 2.2 text-to-video o image-to-video.
  2. Tocas 3 nodos: prompt positivo, negativo, parámetros (tamaño, frames, steps, seed).
  3. Queue. La salida va a output/. Si falta memoria: menos resolución o frames.
  4. Workflow → Export (API format). Ese JSON se envía por HTTP desde una tool.
import requests, time
COMFY = "http://localhost:8188"
def run_comfy(wf: dict) -> str:
    pid = requests.post(f"{COMFY}/prompt", json={"prompt": wf}).json()["prompt_id"]
    while True:
        h = requests.get(f"{COMFY}/history/{pid}").json()
        if pid in h: return str(h[pid]["outputs"])
        time.sleep(5)

Arrancar el proyecto

Crea orquestador.py con Strands Agents: un Agent con BedrockModel
(model_id "us.amazon.nova-pro-v1:0", region us-east-1) y 3 tools
placeholder decoradas con @tool que devuelvan texto fijo:
[transcribir_video(s3_uri)], [traducir_texto(texto, idioma)],
[generar_locucion(texto, idioma)]. Docstrings en español diciendo
qué servicio real usará cada una. System prompt que indique el orden.
Crea también probar_tools.py que llame a cada tool directamente.

Añadir una tool

Añade a orquestador.py una tool [nombre(parametros)] que de momento
devuelva [valor falso], con docstring en español que diga que la
versión real usará [servicio]. Inclúyela en la lista de tools del
Agent, menciónala en el system_prompt y añade su llamada a
probar_tools.py. No cambies nada más.

Hacer real una tool

Sustituye el cuerpo de [traducir_texto] en orquestador.py por una
llamada real a [Amazon Translate con boto3, translate_text,
SourceLanguageCode "auto"] en region us-east-1. Mantén la firma y el
docstring. Si la llamada falla, captura la excepción y devuelve el
valor placeholder anterior con el prefijo "[FALLBACK]". No toques
las demás tools.

Tool que llama a ComfyUI

Crea en comfy_tool.py una tool @tool generar_video_comfy(prompt: str)
que cargue el JSON [workflow_api.json], sustituya el texto del nodo
["6"]["inputs"]["text"] por el prompt, lo envíe a POST
http://localhost:8188/prompt y espere en /history/{id} hasta que
termine. Devuelve el nombre del archivo generado. Usa requests.

Depurar

Al ejecutar python orquestador.py sale este error: [pegar error].
Explica la causa en dos frases y propón el cambio mínimo. No
refactorices nada más.

(AgentCore Runtime, Guardrails). En español, máximo 60 líneas.
